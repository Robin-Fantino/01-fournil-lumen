# Fournil Lumen

## Présentation

Notre client, Fournil Lumen, boulangerie artisanale au feu de bois sur Lyon, souhaite lance les précommandes en ligne ciblant principaleemnt les habitants du quartier.

## Context

Développement du site internet **Fournil Lumen** pour le compte de la boulangerie du même nom en HTML / CSS pur.
C'est un projet d'apprentissage de développement pour me faire les armes dans un contexte "pro" simulé (Ticket, PO, etc.).

Le client souhaite une landing page qui explique le principe de la précommande en ligne et donne envie de réserver son pain pour le lendemain.

## Pour lancer le projet

Télécharger le repository depuis github et puis double cliqué sur le fichier index pour ouvrir la page directement dans votre navigateur.

## Techno

Uniquement du HTML / CSS pour la construction de ce projet.

## Cadre

Projet d'entraînement pour compléter ma formation dans le domaine. Je manque de pratique, donc je pratique.
